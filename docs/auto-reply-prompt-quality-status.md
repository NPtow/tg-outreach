# Auto Reply Prompt Quality Status

Дата: 2026-05-09

## Что исправляли

- Простые входящие вроде `Привет! Чем могу быть полезен?` не должны превращаться в длинный питч.
- Агент не должен сам говорить про отсутствие оплаты или готового сервиса, если собеседник прямо об этом не спросил.
- Квалификация должна спрашивать только недостающий факт.
- После понятной квалификации ответ должен коротко переводить к созвону на 20-30 минут.
- Статус уже назначенной встречи должен звучать как обычный ответ, а не системное уведомление.
