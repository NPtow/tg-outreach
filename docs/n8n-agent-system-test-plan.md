|---|---|---|
| Unit | Validate schema, policy, fallback, idempotency | `pytest tests/test_outreach_runtime.py -k 'n8n or policy or auto_reply'` |

## Critical Fixtures

- Conversation with trust question.
- Conversation with explicit time slot.
- Conversation with “напишите позже”.
- Conversation with hard decline.
- Conversation where user asks for async answer.
- Conversation with fake/unsafe n8n output.
- Conversation where newer user message supersedes older trigger.

## Required Negative Tests

| Case | Expected result |
|---|---|
| n8n webhook timeout | no crash; shadow mode falls back; live mode follows configured fallback |
| malformed n8n JSON | blocked and logged, no send |
| `approved=false` | no send |
| reply contains fake Zoom/calendar link | blocked unless booking record exists |
| reply promises reminder but no reminder payload | blocked |
| duplicate event_id retry | no duplicate Telegram send |
| account not in allowlist | legacy auto-reply path used |
| n8n mode off | current behavior unchanged |

## Replay Acceptance Gates

- [ ] No contradictory scheduling mode.
- [ ] No fake booking/invite claims.
- [ ] Every reminder promise has `ops_action=set_reminder`.
- [ ] Every booking confirmation requires backend booking success.
- [ ] Declines are closed politely.
- [ ] Trust questions are answered before pushing scheduling.
- [ ] Sandbox never sends Telegram messages.

## Shadow Release Gates

- [ ] `N8N_AGENT_MODE=shadow`.
- [ ] n8n decisions appear in `AgentRun`.
- [ ] User-visible replies are still generated by current legacy path.
- [ ] No extra outgoing Telegram messages.
- [ ] Logs include n8n success/failure timing.

## Live Pilot Gates

- [ ] `N8N_AGENT_MODE=live`.
- [ ] Exactly one account or one campaign is allowlisted.
- [ ] `N8N_AGENT_LIVE_FALLBACK=none` unless explicitly changed.
- [ ] One inbound test produces exactly one outgoing reply.
- [ ] AgentRun contains request, decision, policy result, final action.
- [ ] If policy blocks, no message is sent and UI/logs show why.

## Production Rollout Gates

- [ ] Sandbox replay passes on exported replied conversations.
- [ ] Shadow mode has at least 10 live decisions with no safety violations.
- [ ] One-account live pilot succeeds.
- [ ] Rollback is simple: set `N8N_AGENT_MODE=off`.
- [ ] Worker and web deploy from the same GitHub commit.
